리니어 축 배선도

Arduino Mega 2560 하나로 DM542 + STM-4248(리니어 축)과 TMC2209 + OK35STH13(소형 축)을 구동하는 배선입니다. 24V SMPS 1개를 퓨즈 2개로 나눠 두 드라이버에 공급하고, 전원 차단은 SMPS를 꽂은 스위치 멀티탭으로 합니다.

24V + GND (모두 공통) STEP / PUL DIR EN / ENA 5V 로직 · UART 스위치 입력

부품을 누르면 아래 패널에 사양과 연결 정보가 표시되고, 그 부품에 연결된 배선만 진하게 남습니다. 빈 곳을 누르거나 Esc를 누르면 선택이 풀립니다. 선이 교차하는 곳은 연결이 아니며, 점(●)이 찍힌 곳만 연결됩니다.

전원 넣기 전 확인

  • SMPS 출력이 24V인지 테스터로 확인 (29V 어댑터 사용 금지: TMC2209 최대 29V)
  • +V와 GND가 바뀌지 않았는지, 퓨즈가 끼워져 있는지
  • SMPS -V, DM542 GND, TMC2209 GND, Mega GND가 모두 이어져 있는지
  • SMPS를 꽂은 멀티탭 스위치를 손 닿는 곳에 두기 (끄면 두 드라이버가 함께 꺼짐)
  • 모터 선은 전원을 끈 상태에서만 꽂고 빼기
  • 24V를 Mega VIN에 연결하지 않기 (허용 7~12V)

TMC2209 모듈은 제조사마다 핀 이름이 다릅니다 (A1/A2 ↔ 1A/1B ↔ M1A/M1B, VIO ↔ VDD ↔ VCC_IO). 배선도는 BIGTREETECH 모듈 기준이므로 구매한 모듈 뒷면 실크 인쇄와 대조하세요.
